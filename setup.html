مراحل تنظیم

۱

توکن امن بساز

در Cloudflare یک API Token تازه با مجوز لازم برای مدیریت Workers و D1 و Pages بساز. هر توکنی که قبلاً در چت یا فضای عمومی افشا شده باید لغو شود؛ دوباره از آن استفاده نکن.

۲

سه Secret به GitHub اضافه کن

در صفحه GitHub Secrets روی New repository secret بزن. نام‌ها: CLOUDFLARE_API_TOKEN، CLOUDFLARE_ACCOUNT_ID و NOGHREH_ADMIN_TOKEN. سومی باید یک راز تصادفی و طولانی با حداقل ۳۲ نویسه باشد؛ آن را فقط برای احراز هویت API استفاده کن و در کد ننویس.

۳

استقرار را اجرا کن

برای رابط وب workflow با نام Deploy Noghreh Panel to Cloudflare Pages را اجرا کن. برای API و دیتابیس، workflow با نام Deploy Noghreh API and D1 را اجرا کن. اجرای API فقط بعد از افزودن هر سه Secret ممکن است. اگر خطا دیدی، متن خطا را بدون هیچ توکنی بررسی کن.

این صفحه فقط راهنمای امن راه‌اندازی است و توکن را ارسال یا نگهداری نمی‌کند. API اولیه مدیریت کاربران و ساختار D1 اضافه شده‌اند، اما workflow هنوز در حساب Cloudflare اجرا و تأیید نشده و رابط فعلی هنوز به API متصل نیست. سرویس واقعی VLESS، لینک‌های subscription، اندازه‌گیری ترافیک و محدودسازی دستگاه هنوز تکمیل نشده‌اند.
